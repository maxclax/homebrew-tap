# maxclax/tap

Homebrew cask for apps by [maxclax](https://maxclax.com).

```sh
brew install --cask maxclax/tap/sunclax
```

- **Sunclax** — a keystroke counter and typing trainer that never records what you type.
  [maxclax.com/sunclax](https://maxclax.com/sunclax/)

It needs macOS 26 or newer on Apple silicon.

It updates itself; `brew upgrade` is not needed.

`brew uninstall --zap --cask sunclax` also removes the app's settings and caches — never your data:
Sunclax's typing history stays in the folder you chose.
