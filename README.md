# maxclax/tap

Homebrew casks for apps by [maxclax](https://maxclax.com).

```sh
brew install --cask maxclax/tap/sunclax
```

- **Sunclax** — a keystroke counter and typing trainer for macOS that never records what you type.
  macOS 26 or newer, Apple silicon. [maxclax.com/sunclax](https://maxclax.com/sunclax/)

Sunclax updates itself; `brew upgrade` is not needed. `brew uninstall --zap --cask sunclax` also
removes its settings and caches — never your typing history, which stays in the folder you chose.
